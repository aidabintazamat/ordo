Как работать в ORDO: пошагово

Как открыть и заполнить циклограмму?

Откройте «Методический кабинет → Циклограмма», выберите неделю и группу. Готовую циклограмму Ordo можно взять как есть или собрать свою.

  1. В меню слева откройте Методический кабинет → Циклограмма.

  2. Выберите учебный год, неделю и возрастную группу.

  3. Вкладка Циклограмма Ordo — готовый план. Вкладка Моя циклограмма — ваш план.

  4. Галочка Использовать циклограмму Ordo включает готовый план для группы. Распечатать — печать.

  5. Во вкладке «Моя циклограмма» нажмите Добавить урок в нужный день.

  6. Выберите образовательную область, деятельность и урок, затем нажмите Сохранить.

Как составить учебный план?

Откройте «Методический кабинет → Учебный план». План можно сформировать автоматически для всех групп или добавить вручную.

  1. В меню слева откройте Методический кабинет → Учебный план.

  2. Выберите группу и учебный год в фильтрах.

  3. Нажмите Сформировать для всех групп, чтобы ORDO составил план сам.

  4. Или нажмите Добавить план и заполните его вручную.

  5. Глаз в строке открывает план для просмотра.

Как сформировать перспективный план?

Откройте «Методический кабинет → Перспективный план» и нажмите «Сформировать для всех групп» или «Добавить план».

  1. В меню слева откройте Методический кабинет → Перспективный план.

  2. Нажмите Сформировать для всех групп — план появится по каждой группе.

  3. Чтобы составить план вручную, нажмите Добавить план.

  4. Карандаш в строке открывает план для правки.

Как провести мониторинг навыков детей?

Откройте «Методический кабинет → Мониторинг» и нажмите «Провести». Результаты показываются в процентах по каждому навыку.

  1. В меню слева откройте Методический кабинет → Мониторинг.

  2. Нажмите Провести, чтобы начать новый мониторинг.

  3. Чтобы найти результаты, выберите группу и вид мониторинга.

  4. Нажмите Заполнить, чтобы внести оценки по ребёнку.

  5. Нажмите Свод по группе, чтобы увидеть итог по всей группе.

Как найти урок (ОД) или добавить свой?

Откройте «Методический кабинет → Список ОД». Готовые уроки — во вкладке «Уроки Ordo», ваши — в «Мои уроки».

  1. В меню слева откройте Методический кабинет → Список ОД.

  2. Выберите вкладку Уроки Ordo или Мои уроки.

  3. Сузьте список фильтрами: направление, предмет, тип ОД, возраст.

  4. Чтобы создать свой урок, нажмите Добавить урок.
